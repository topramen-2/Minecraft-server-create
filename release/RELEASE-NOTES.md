**Required:** Minecraft **Java Edition 1.21.1**, NeoForge **21.1.265**, **64-bit Java 21**, game memory **8 GB** (`-Xmx8G`). A computer with **16 GB or more total RAM** is recommended. You need a Minecraft Java Edition account and internet access for installation.

### The short version

1. Download and extract the complete ZIP into a **new empty folder**.
2. Follow the Windows or Linux guide above. Each explains Java, installing NeoForge, creating a Minecraft Launcher installation, selecting the game folder, and setting 8 GB RAM.
3. Launch the Alaska installation and add the server address Jackson provides under **Multiplayer**.

**Do not download GitHub's “Source code (zip)” or “Source code (tar.gz)” for installation.** Use the named CLIENT.zip above. Those source-code downloads are automatically generated by GitHub and are not the ready-to-play pack.

### Already have an older pack?

Keep it as a backup. Extract this ZIP into a new folder and create a new launcher installation pointing to it. Do not merge old mods into this pack. There is no patch chain to follow.
