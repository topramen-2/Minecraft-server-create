**Minecraft Java Edition 1.21.1 · NeoForge 21.1.265 · 64-bit Java 21 · 8 GB game RAM**

Use the named **CLIENT.zip** asset on the latest release page. The green GitHub **Code → Download ZIP** button and release **Source code** assets do not download the ready-to-play client pack.

Start with the guide for your operating system. It explains downloading, extracting, installing Java/NeoForge, creating a launcher installation, selecting the correct game folder, and setting memory to `-Xmx8G`.

Ask Jackson for the server address. Keep an older installation as a backup and install the new pack into a separate folder.
