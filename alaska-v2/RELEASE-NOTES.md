# Create Kingdoms Alaska — v2.0.0-alaska

A fresh-world successor to Create Kingdoms for Minecraft 1.21.1 / NeoForge. Replaces TerraForged in the new installation with Tectonic, Regions Unexplored, Project: Vibrant Journeys and Snow Under Trees, plus northern-biome and spawn configuration.

Adds wildlife, seasons, farming, fishing, furniture and client atmosphere. Preserves the live server's existing Create/MineColonies/AE2 baseline. Players begin in a new Survival world without old inventory, experience, colonies or progression.

Extract the client ZIP into an empty game directory. Install the exact NeoForge version printed in INSTALL.txt and select that directory in the launcher. Do not merge with the old pack. Shaders are supplied but initially disabled.

Substitutions include Sodium/Iris, Inventory Profiles Next and unofficial ports of Alex's Mobs and Spartan Weaponry. Immersive Weathering Renewed is a beta port with incomplete upstream feature coverage. North American Fishes, Simple Farming, Salt and Hearth & Home are omitted because matching builds were not verified. See alaska-v2/MOD-DECISIONS.md for all pinned selections.

Prepared with checksum and dependency-presence checks and a simulated migration test. This prerelease requires real server/client validation. The original v1.0.0 installation and world remain available for rollback; the new world does not import old progression.
