# Create Kingdoms Alaska v2.0.2

Adds Create Aeronautics 1.3.2 and Sable 2.0.6.
Updates Distant Horizons to 3.3.3, Sodium to 0.8.13,
and Iris to 1.8.14 Beta 1.

Requires Minecraft 1.21.1, NeoForge 21.1.265, and Java 21.

User-confirmed checks: server startup, multiplayer join, distant
terrain with shaders, and the requested Aeronautics movement/rejoin test.
This is a smoke-tested pack, not exhaustive compatibility certification.
Previous pending tests, including two-player map sync, remain pending.

Installation:
- Back up your existing installation.
- Use a fresh game directory with NeoForge 21.1.265.
- Extract the client ZIP into that directory.
- Do not merge old and new mods folders.
- Personal maps, worlds, server addresses, and disabled mods are excluded.
- Existing release configuration is retained; personal graphics settings
  are not imported from the test profile.
- DH may need time to download or generate distant terrain.
- Server administrators must use DH 3.3.3 for the tested server setup.
- Iris and Sodium are client-side mods.

Optional visuals used in testing:
Complementary Unbound r5.9.3 and Patrix 1.21 32x basic.
If absent from the archive, obtain them from their official project pages:
https://modrinth.com/shader/complementary-unbound
https://modrinth.com/resourcepack/patrix
Select them manually in Shader Packs and Resource Packs.

Known startup warnings include the Copycats catwalk physics tag and
DH distant generation for the AE2 spatial-storage dimension.
